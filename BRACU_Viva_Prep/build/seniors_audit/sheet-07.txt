B23: Completeness
E23: What is a Complete Algorithm?
A complete algorithm is one that:

Terminates for all valid inputs.
Produces a correct solution if one exists.
Indicates failure when no valid solution exists.
G23: BFS is complete, given width of tree is finite
DFS is not complete, for infinite branches
Iterative Deepening Search and Depth Limited Search are complete

B32: Zero Sum Game
E32: A zero-sum game is a situation where one player's gain is equal to another player's loss, resulting in a net gain of zero.
B34: Minimax Algorithm
C34: a. Complete when the game tree is finite and there is eventually a terminal state

b. Minimax is kind of like DFS, but difference in the sense that it evaluates nodes and also alternates between maximum and minimum nodes. DFS merely visits nodes and doesn't do any alteration

c. Minimax fails with randomness because it assumes all moves are deliberate decisions aimed at maximizing or minimizing utility.

d. Doesn't work for more than two players, for that we can explore Nash Equilibrium
D34: Time Complexity: O(b^d)
E34: The Minimax algorithm is a decision-making algorithm used in two-player, zero-sum games, where one player's gain is the other player's loss. It works by recursively exploring all possible moves in the game tree, assuming both players play optimally: the maximizing player aims to maximize their score, while the minimizing player tries to minimize the maximizing player's score. The algorithm evaluates all possible outcomes and chooses the move that leads to the best possible result for the current player, assuming the opponent also plays optimally. It is typically used in games like chess or tic-tac-toe.
